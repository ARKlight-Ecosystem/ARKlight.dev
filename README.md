# ARKlight website

The public website for [ARKlight](https://github.com/ARKlight-Ecosystem/ARKlight),
written in ARKlight itself: a home page, getting started, a tutorial lesson, a
reference, an example, and the project pages. Modeled on the shape of the Svelte v2
site (see `docs/SVELTE-REFERENCE.md` for what that reference checkout actually is).

Written against **ARKlight v0.70.1** (`main`, commit `10a2225`).

* [Getting started](content/start.py) · [Tutorial](content/tutorial.py) · [Reference](content/reference.py) · [Examples](content/examples.py)

## Quick start

```bash
pip install arklight
export ARKLIGHT_ACCEPT_LICENSE=1      # only after reading ARKlight's LICENSE
export SITE_URL=https://your-domain   # no default on purpose; canonical tags need it

make build       # check -> generate site.py -> arklight build -> sitemap/robots
make serve       # http://localhost:8000, with extensionless URLs like GitHub Pages
```

`make help` lists everything.

## Layout

```
pages/manifest.py       the source of truth: 15 routes, section, nav label
content/*.py             page content as plain Python data (title, description, blocks)
components/render.py     turns content into ARKlight Page(...) trees; SEO head tags
site.py                  GENERATED by scripts/gen_site.py (routes must be literal decorators)
scripts/                 gen_site, check_content, postbuild (sitemap/robots), serve
assets/                  favicon.svg, og-image.png (placeholder, replace)
docs/                    architecture, authoring, SEO, Svelte-reference notes
reference/               Svelte v2.16.1 source (shallow, no .git), see docs/SVELTE-REFERENCE.md
```

## Known gaps (honest list)

* `assets/og-image.png` is a plain placeholder.
* The layout was verified by inspecting generated HTML, **not** by looking at it in a browser.
* This is the core site only: one tutorial lesson, one example, and the reference pages
  that are written. It covers "what is it, how do I start, what are the rules, what are
  the limits" and nothing past that; it does not try to be a full docs site.
