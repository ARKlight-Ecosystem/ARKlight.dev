# ARKlight website

The public website for [ARKlight](https://github.com/ARKlight-Ecosystem/ARKlight),
written in ARKlight itself. Modeled on the shape of the Svelte v2 site: a home page,
tutorial, reference, examples, and project pages.

Written against **ARKlight v0.70.1** (`main`, commit `10a2225`).

## Two stops

| Stop | What | Pages | Command |
|---|---|---|---|
| **Pitstop** (phase 1) | A launch-quality core site | 15 (14 + 404) | `make pitstop` |
| **Final** (phase 2) | The full site | 36 (35 + 404) | `make release` |

Phase 1 is complete and builds. Phase 2 has **21 pages that are still draft outlines**
(real titles, descriptions, and section headings with a note on what each section must cover).
Release builds refuse to ship drafts. See `docs/CONTENT-STATUS.md` for the per-page list.

## Quick start

```bash
pip install arklight
export ARKLIGHT_ACCEPT_LICENSE=1      # only after reading ARKlight's LICENSE
export SITE_URL=https://your-domain   # no default on purpose; canonical tags need it

make pitstop        # check -> generate routes -> build -> sitemap/robots
make serve          # http://localhost:8000, with extensionless URLs like GitHub Pages
```

`make help` lists everything. For a build that ignores the draft gate (to preview
phase 2 with its DRAFT banners): `make dev2`.

## Layout

```
pages/manifest.py       THE source of truth: 36 routes, section, phase, nav label
content/*.py            page content as plain Python data (title, description, blocks)
components/render.py    turns content into ARKlight Page(...) trees; SEO head tags
site.py                 GENERATED by scripts/gen_site.py (routes must be literal decorators)
pages/active.py         GENERATED: which routes exist in the current phase
scripts/                gen_site, check_content, postbuild (sitemap/robots), serve, status
assets/                 favicon.svg, og-image.png (placeholder, replace)
docs/                   plan, architecture, authoring, SEO, deploy, content status
reference/              Svelte v2.16.1 source (shallow, no .git), see docs/SVELTE-REFERENCE.md
.github/workflows/      GitHub Pages deploy (UNTESTED)
```

## Known gaps (honest list)

- 21 draft pages need writing; the two comparison pages must be fact-checked against Eleventy's and Astro's current docs.
- The production domain is not chosen. `SITE_URL` is a placeholder and release builds fail until it is set.
- `assets/og-image.png` is a plain placeholder.
- The layout was verified by inspecting generated HTML, **not** by looking at it in a browser.
- The GitHub Actions workflow and the Debian install commands have not been run.
